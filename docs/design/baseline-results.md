# 基线仿真结果

## 1. 运行配置

2026-09-27，MATLAB R2025b，通过 `sim('baseline')` 实际执行 [`baseline.slx`](../../matlab/baseline/baseline.slx)。单径复基带 AWGN、理想同步、三信道同时发送，每个噪声点 100 批、400 个业务帧，共 68,800 个有效数据位。帧结构和噪声归一化见[基线设计](baseline.md)。

## 2. BER 与 FER

| 业务有效数据位 Eb/N0 | 错误位数 | BER | 错误业务帧数 | FER |
| --- | ---: | ---: | ---: | ---: |
| 无噪声 | 0 | 0 | 0 | 0 |
| -4 dB | 33199 | 0.482544 | 400 | 1 |
| -2 dB | 30147 | 0.438183 | 400 | 1 |
| 0 dB | 16770 | 0.243750 | 392 | 0.98 |
| 2 dB | 1117 | 0.016236 | 114 | 0.285 |
| 4 dB | 0 | 0 | 0 | 0 |
| 6 dB | 0 | 0 | 0 | 0 |

4 dB 和 6 dB 的零错误仅表示本次有限样本未观察到错误，不能当作真实 BER 为零。零误码、68,800 位的单侧 95% BER 上界约为 4.35×10^-5；400 个零错误帧对应的 FER 上界约为 0.00746。图中零错误点用 0.5/N 的绘图下限显示，CSV 保留原始零值。

## 3. 验证内容与边界

- 无噪声端到端有效数据逐位一致，CRC 检查通过；业务 Walsh 相关输出与发端符号误差小于 10^-12。
- 同一数据、噪声种子重复运行，接收 I/Q 逐样本一致。
- 单批复噪声实测总方差与配置值相差小于 3%。
- CRC 与独立移位寄存器实现逐位比较；卷积码与独立八进制抽头运算比较。
- 短 PN 插零后的长度、平衡性、起点及移除插零后的循环递推一致性得到检查。
- 三条 Walsh 码相互正交，同步编码状态在重复测试模式的批次边界连续。

本次没有进行标准参考收发机逐波形互通比对，也没有完成理论编码 BER 曲线或定点损失验收。测试范围限于当前已列明的浮点基线。
