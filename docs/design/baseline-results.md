# 基线仿真结果

## 1. 运行配置

2026-09-27，在 MATLAB R2025b 中实际运行 [`baseline.slx`](../../matlab/baseline/baseline.slx)。本次采用 [v2 载荷定义](../decisions/02-baseline-payload.md)：每个 20 ms 业务帧都是 192 个业务位，无 CRC、无尾零；逐帧零状态卷积编码，接收端采用截断模式非量化 Viterbi。

信道为单径复基带 AWGN、理想同步，导频、同步测试分支和业务信道同时发送。扫描 −4～6 dB，步长 0.25 dB，共 41 个实测点；每点 1000 批，即 4000 个业务帧、768,000 个业务位。另完成无噪声 768,000 位检查，错误数为零；该诊断不放入 BER 扫描 CSV。

## 3. 验证内容

- 无噪声 768,000 个业务位逐位恢复；单批解扩软符号与发端符号误差小于 10^-12。
- 每批业务输入、帧组织输出和最终接收输出均为 768 位，编码后为 1536 位；没有插入或剔除 CRC、尾比特。
- 独立卷积抽头实现与编码器逐位一致；包含非零最终状态的帧可以经截断译码完整恢复。
- BER 计数覆盖全部 768 位；注入最后一个业务位错误得到准确的 1/768。
- 短 PN 的长度、平衡性、循环递推、Walsh 正交性，以及固定同步模式连续三批的编码一致性均通过检查。
- 同一随机种子的两次仿真接收 I/Q 完全一致。2 dB 诊断批次中，复噪声总方差实测约 81.027，目标约 80.7625，相差约 0.33%。
- 旧版配置可自动迁移到 v2；模型顶层 BER 显示器与新输入尺寸均已实际运行检查。

## 5. 比较边界

v2 与旧版同时改变了有效数据位数、Eb 定义和译码边界：不再利用尾零提供的已知最终状态。因此旧版 CRC/尾零曲线不能直接用来评价本版是否提升性能。旧图和 CSV 仅在 archive 中保留，当前入口使用 ber.png 和 ber.csv。

当前仍未实现完整标准消息、长码扰码、功控位和成形滤波，也未进行标准参考收发机互通或定点损失验收。
