# 不同速率关系

本项目固定扩频码片速率为

```text
Rc = 1.2288 Mchip/s
```

64 位 Walsh 码使每个 Walsh 符号占 64 个码片，因此统一的 Walsh 输入符号率为

```text
Rs = Rc / 64 = 19.2 ksymbol/s
```

业务比特先经过码率为 `1/2` 的卷积编码，再通过重复进行速率适配：

| 业务信息速率 `Rb` | 卷积编码后 | 重复倍数 | 适配后 Walsh 符号率 | `Rc/Rb`（chip/信息 bit） | 处理增益 `10log10(Rc/Rb)` |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2.4 kbps | 4.8 ksymbol/s | 4 | 19.2 ksymbol/s | 512 | 27.09 dB |
| 4.8 kbps | 9.6 ksymbol/s | 2 | 19.2 ksymbol/s | 256 | 24.08 dB |
| 9.6 kbps | 19.2 ksymbol/s | 1 | 19.2 ksymbol/s | 128 | 21.07 dB |

所以三档业务最终都以 `19.2 ksymbol/s` 进入 64 位 Walsh 扩频器，并都得到相同的 `1.2288 Mchip/s` 码片速率。一个 Walsh 符号持续

```text
64 / 1.2288e6 = 52.0833 us
```

射频工作频率 `fc = 800 MHz` 是载波中心频率，与上述基带速率不是编码或扩频倍数关系。数值上：

```text
fc / Rc = 800e6 / 1.2288e6 = 651.0417
```

即一个码片周期约为 `813.802 ns`，其中约有 `651.04` 个 800 MHz 载波周期。该比值不要求为整数；实际系统通常用频率合成器产生 800 MHz 载波，而码片时钟由 `36.864 MHz / 30 = 1.2288 MHz` 得到。占用带宽主要由码片速率和脉冲成形决定，800 MHz 只决定信号所在的射频频段。
