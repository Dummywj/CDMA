# 老师十步法：CDMA 无线数据传输链路设计与实现教学

本文在《CDMA无线数据传输链路设计教学》的基础上，按照老师推荐的十个步骤重新组织项目。目标不是一次搭出完整系统，而是建立十个可运行、可验证、可回退的版本：每一步只增加一类新问题，并保留上一阶段的测试作为回归基线。

最终系统参考 IS-95 前向链路，包含 BPSK/QPSK、PN 短码、Walsh 逻辑信道、同步捕获与跟踪、导频相位校正、两径 Searcher/Rake、卷积码与交织、定点化和 RTL 实现。

---

## 1. 总体目标与基本参数

### 1.1 最终链路

```text
发送端
  信息源
    -> CRC/FEC/重复
    -> 块交织
    -> 帧结构与速率适配
    -> Walsh 逻辑信道扩频
    -> 逻辑信道功率分配与合路
    -> I/Q PN 短码扩频
    -> QPSK 复基带

信道
  单径 AWGN 或两径衰落信道
  + 接收机唯一一份热噪声
  + 收发时钟频差

接收端
  Searcher/PN 捕获
    -> Early-Late 码跟踪
    -> Finger 解扩
    -> 导频辅助信道估计与相位校正
    -> Rake 最大比合并
    -> Walsh 信道分离
    -> 帧同步
    -> 解交织/FEC 译码/CRC
    -> BER、FER 与同步性能统计
```

### 1.2 建议冻结的参数

| 参数 | 建议值或要求 |
| --- | --- |
| 射频工作频率 | 800 MHz；前九步以等效复基带仿真为主 |
| 晶振频率 | 36.864 MHz |
| 码片时钟 | 1.2288 MHz，即晶振 30 分频 |
| PN 码 | IS-95 I/Q 短码；具体多项式、初态和零插入规则必须以课程指定标准及测试向量为准 |
| Walsh 码长 | 64 chip |
| Walsh 符号率 | `1.2288 Mcps / 64 = 19.2 ksymbol/s` |
| 调制方式 | 第一步支持 BPSK 和 Gray QPSK；CDMA 合路后使用复基带 QPSK |
| 逻辑信道 | 导频、同步、业务各 1 条 |
| 同步信道信息速率 | 1.2 kbps |
| 业务信道信息速率 | 本文先完成 9.6 kbps，再扩展 4.8/2.4 kbps |
| FEC | IS-95 卷积码，建议先实现 `K=9, R=1/2`；生成多项式按指定标准冻结 |
| 多径 | 2 径，延迟至少相差 1 chip，功率和相位可配置 |
| Rake | 2 个 Finger，最大比合并 MRC |
| 定点指标 | AWGN 下相对浮点基线在目标 BER/FER 处损失不超过 0.4 dB |

标准相关参数不能凭记忆填写。项目开始时应建立 `system_config` 和版本化参数表，将 PN 多项式、Walsh 编号、卷积码多项式、CRC 多项式、比特顺序和初态全部冻结；任何修改都必须同步修改测试向量。

### 1.3 三个时间单位必须分清

| 名称 | 含义 | 本系统中的典型速率 |
| --- | --- | --- |
| bit | 编码前或编码后的二进制信息 | 1.2/9.6 kbps 等 |
| symbol | 调制符号或进入 Walsh 扩频的符号 | 19.2 ksymbol/s |
| chip | PN/Walsh 扩频后的高速码片 | 1.2288 Mchip/s |

所有模块接口都应注明数据率、每帧长度、实数或复数、幅度归一化方式，不能只写“输入数据”和“输出数据”。

## 3. 第一步：构建单路 BPSK/QPSK 基础链路

### 3.1 本步目标

先建立不含编码、不含扩频、不含同步的单路数据链路：

```text
随机比特 -> BPSK/QPSK 调制 -> AWGN -> 相干解调 -> BER
```

这一步的输出是整个项目的理论基线。后续每增加一个模块，都要在相同 `Eb/N0` 定义下和本基线比较。

### 3.2 调制定义

BPSK 采用：

```text
0 -> +1
1 -> -1
```

QPSK 建议采用 Gray 映射，并归一化到 `Es=1`：

| 比特 | 符号 |
| --- | --- |
| 00 | `( 1 + j)/sqrt(2)` |
| 01 | `(-1 + j)/sqrt(2)` |
| 11 | `(-1 - j)/sqrt(2)` |
| 10 | `( 1 - j)/sqrt(2)` |

必须把比特顺序、I/Q 对应关系和复数符号正负号写入接口规范。调制器和解调器“看起来对称”并不等于映射一致。

### 3.3 AWGN 与理论曲线

若 QPSK 已归一化为 `Es=1`，每符号 2 bit，则：

```text
Eb = Es / 2
gamma_b = 10^(EbN0_dB/10)
N0 = Eb / gamma_b
n = sqrt(N0/2) * (randn + j*randn)
r = s + n
```

相干 Gray QPSK 与 BPSK 的理论比特误码率均为：

```text
Pb = Q(sqrt(2*Eb/N0))
```

仿真应采用“达到最小错误数或最大比特数才停止”的规则，例如每个信噪比点至少累计 200 个错误，或达到 `1e7` bit，避免高信噪比点统计失真。

### 3.4 本步实验

1. 固定短序列，验证映射表和硬判决。
2. 无噪声端到端测试，要求逐比特一致。
3. 绘制低、高两个 `Eb/N0` 下的星座图。
4. 扫描 `Eb/N0=0:1:10 dB`，分别绘制 BPSK、QPSK 和理论 BER。
5. 故意将 `Es/Eb` 换算设置错误，观察曲线平移，用于理解 3 dB 问题。

### 3.5 验收标准

| 验收项 | 要求 |
| --- | --- |
| 无噪声 BER | 0 |
| 星座平均能量 | 与设计归一化值一致 |
| BER 趋势 | 随 `Eb/N0` 增加而下降 |
| 理论偏差 | 统计置信范围内贴近理论曲线，不出现固定 dB 平移 |
| 软件结构 | 信息源、调制、信道、解调、统计相互独立 |

## 4. 第二步：加入 PN 码，形成单路直接序列扩频链路

### 4.1 本步目标

保持理想信道时钟和 PN 相位已知，将基础链路扩展为：

```text
数据符号 -> PN 扩频 -> 理想/AWGN 信道 -> 同相 PN 解扩 -> 数据判决
```

本步重点不是捕获，而是先彻底解决 PN 发生器、复数扩频/解扩、处理增益、群时延和基线对齐。

### 4.2 PN 发生器

PN 发生器通常由 LFSR 构成。实现时必须固定：

```text
寄存器方向
反馈抽头
输出抽头
初始状态
0/1 到 +/-1 的映射
序列周期
复位时刻与“零相位”的定义
```

建议先用一个短周期 PN 完成单元测试，再切换到 IS-95 I/Q 短码。最终短码必须通过标准参考向量验证前若干百个 chip，不能仅以“自相关峰明显”作为正确性证明。

### 4.3 实数和复数扩频

若输入为实 BPSK 符号 `a[k]`，可用实 PN：

```text
x[kL+l] = a[k] * p[l] / sqrt(L)
```

若输入为复 QPSK 符号 `a[k]`，可定义复 PN：

```text
p_c[n] = (p_I[n] + j*p_Q[n]) / sqrt(2)
x[n] = a[floor(n/L)] * p_c[n] / sqrt(L)
```

解扩为：

```text
z[k] = sum(x[kL+l] * conj(p_c[kL+l])) / sqrt(L)
```

这里给出的是一种能量守恒归一化。也可以让每个 chip 幅度保持为 1，再在解扩后除以 `L`；两种方式都可行，但全项目只能选择一种。扩频必须乘 PN，解扩必须乘 PN 的共轭，这是复数扩频最容易遗漏的地方。

### 4.4 处理增益的正确理解

扩频因子为：

```text
L = Rc / Rs
Gp = 10*log10(L) dB
```

处理增益表示相关解扩对宽带噪声或窄带干扰的抑制能力。若仿真始终按“每个信息 bit 的 `Eb/N0`”加噪，扩频不会凭空改善纯 AWGN 下的理论 BER；若固定的是每 chip 信噪比，则解扩后的符号信噪比会提高约 `L` 倍。报告必须说明固定的是 `Eb/N0`、`Es/N0` 还是 chip SNR。

### 4.5 基线对齐

扩频、滤波、缓存和积分会引入延迟。禁止人工删除若干样点直到 BER 变为 0。每个模块应声明确定性延迟，系统用统一标签或有效信号对齐：

```text
total_latency = TX_latency + channel_delay + RX_latency
```

BER 统计只比较同一原始索引的数据。建议给每帧附加仿真专用序号，调通后再移除。

### 4.6 验收标准

| 验收项 | 要求 |
| --- | --- |
| PN 序列 | 周期、初态、参考向量正确 |
| 自相关 | 零延迟主峰明显，非零延迟符合所选 PN 特性 |
| 理想解扩 | 无噪声时输出符号与输入一致 |
| 复数运算 | 使用共轭解扩，I/Q 无交换和符号翻转 |
| 能量 | 扩频前后符合选定归一化规则 |
| 基线 | 延迟由模型计算，逐帧自动对齐 |

## 5. 第三步：在理想时钟下实现 PN 捕获

### 5.1 问题边界

本步仍假设 Tx/Rx 码片时钟频率完全相同，但接收端不知道发送端 PN 初相。由于没有频偏，接收端只需要在一个 PN 周期内搜索固定码相位。

```text
已知：码率、PN 结构、采样时刻
未知：PN 起始相位
输出：捕获成功标志、路径时延、对齐后的 PN 零相位
```

### 5.2 最简单捕获器

对每个候选相位 `tau` 做相关：

```text
C[tau] = sum(r[n+tau] * conj(p[n]), n=0...Ncoh-1)
M[tau] = |C[tau]|^2
tau_hat = argmax(M[tau])
```

初版可使用串行滑动相关搜索；仿真加速版可使用 FFT 循环相关。二者必须在同一固定向量上得到相同峰值位置。

为了降低数据信号正负翻转对捕获的影响，可采用已知前导、导频，或对多个短相关块做非相干累加：

```text
M[tau] = sum_m |C_m[tau]|^2
```

### 5.3 门限与确认

不能只取全局最大值就宣布捕获。建议采用相对门限：

```text
peak_to_floor = max(M) / median(M)
```

峰值超过门限后进入确认态，连续若干块保持在允许窗口内才输出 `LOCK`。门限应通过纯噪声下虚警概率和有信号下检测概率确定。

### 5.4 PN 零相位对齐

必须区分三个量：

```text
传播时延 tau_path
相关器峰值对应的窗口索引 tau_peak
PN 发生器定义的零相位 tau_pn0
```

相关器自身积分窗和流水延迟会使 `tau_peak` 不等于数组中的第一个有效样点。用无噪声冲激式测试标定固定偏置：

```text
tau_pn0 = tau_peak - correlator_latency - configured_path_delay
```

接收 PN NCO/LFSR 应在统一的帧边界装载相位，而不是异步清零造成一 chip 偏差。

### 5.5 状态机与验收

```text
IDLE -> SEARCH -> VERIFY -> LOCK
                 |          |
                 +--失败----+
```

| 验收项 | 要求 |
| --- | --- |
| 全相位遍历 | 任意注入 PN 相位均能返回正确结果 |
| 无噪声误差 | 估计码相位误差为 0 chip |
| 捕获概率 | 给出随输入 SNR 变化的检测概率 `Pd` |
| 虚警概率 | 纯噪声下统计 `Pfa` |
| 捕获时间 | 给出平均和最坏搜索时间 |
| 回归 | 捕获后第二步链路 BER 恢复到理想同步基线 |

## 6. 第四步：加入 Walsh 逻辑信道、帧结构与功率分配

### 6.1 本步目标

在单个物理前向链路中加入导频、同步和业务三个逻辑信道：

```text
导频符号 -> Wpilot  --乘 sqrt(Ppilot)--\
同步数据 -> Wsync   --乘 sqrt(Psync) ---+-> 相加 -> I/Q PN -> 信道
业务数据 -> Wtraffic--乘 sqrt(Ptraffic)-/
```

接收端完成 PN 解扩、Walsh 分离、导频相位估计和校正、帧同步，并将业务性能与第一步/第二步基线比较。

### 6.2 Walsh 扩频与信道分离

使用 Hadamard 矩阵产生长度 64 的 Walsh 码，并固定编号。码值统一映射到 `+1/-1`。理想对齐时：

```text
sum(Wi[n] * Wj[n]) = 64, i=j
sum(Wi[n] * Wj[n]) = 0,  i!=j
```

Walsh 码只在时间对齐时正交，因此码片错位、频偏、多径和非整数延迟都会造成信道间干扰。

每个 Walsh 符号持续：

```text
Tw = 64 / 1.2288e6 = 52.0833 us
Rw = 19.2 ksymbol/s
```

各低速逻辑信道必须通过重复或速率匹配变成 19.2 ksymbol/s 后才能逐个 Walsh 符号扩频。

### 6.3 建议帧结构

为兼容同步信道的 `26.666... ms` 块和业务信道的 `20 ms` 帧，可用 `80 ms` 作为联合仿真超帧：

```text
80 ms 超帧
  = 3 个同步交织块 x 26.666... ms
  = 4 个业务帧 x 20 ms
  = 1536 个 Walsh 符号
  = 98304 chip
```

导频连续发送已知符号，不单独分帧。同步信道携带固定同步字、超帧计数或系统时间；业务帧含帧号和测试载荷。第四步暂不加入正式 FEC，但要先固定帧边界和速率接口，第八步再替换为编码后的真实格式。

### 6.4 功率分配与唯一噪声源

设归一化后的三路扩频波形平均功率均为 1，则：

```text
x[n] = sqrt(alpha_p)*x_p[n]
     + sqrt(alpha_s)*x_s[n]
     + sqrt(alpha_t)*x_t[n]

alpha_p + alpha_s + alpha_t = 1
```

`alpha` 是功率比例，幅度权重必须取平方根。初始可用一组便于调试的比例，例如 `0.5/0.1/0.4`，最终值应通过链路预算和性能扫描确定。

接收端底噪只添加一次：

```text
N = k*Tsys*B*F
```

其中 `k` 为玻尔兹曼常数，`Tsys` 为系统噪声温度，`B` 为接收等效噪声带宽，`F` 为线性噪声系数；若噪声系数已经折算进等效噪声温度，就不能重复相乘。不能给三个逻辑信道分别加 AWGN，也不能因发射功率分配而改变接收机热噪声。

对信息信道，理想情况下可由功率预算估计：

```text
Eb_i/N0 = P_rx,i / (Rb_i * N0)
P_rx,i = alpha_i * P_rx,total
```

导频不承载信息 bit，应报告每 chip 或每 Walsh 符号的 `Ec/N0`、`Es/N0`，不要人为定义导频 `Eb/N0`。仿真中还应直接测量解扩后均值功率与误差方差，和上述理论值交叉检查。

### 6.5 导频辅助相位估计与校正

导频 Walsh 解扩后得到：

```text
y_p[k] = h[k]*sqrt(Pp)*d_p[k] + v[k]
h_hat[k] = LPF(y_p[k]*conj(d_p[k])) / sqrt(Pp)
```

同步和业务信号可用以下任一等价形式校正：

```text
y_eq = y * conj(h_hat) / (|h_hat|^2 + epsilon)
```

或仅做相位旋转：

```text
y_rot = y * exp(-j*angle(h_hat))
```

第一种同时均衡幅度，第二种保留软信息幅度。实现时要记录导频平均窗带来的延迟，并与业务支路对齐。

### 6.6 帧同步

同步信道使用已知同步字。接收端对解扩后的软符号做相关，输出：

```text
frame_start
superframe_start
frame_index
sync_locked
```

帧同步应采用“搜索、确认、保持、失锁”状态机，并在存在少量比特错误时仍能保持。不能直接用仿真发送端的帧起点作为接收端帧起点，发送端标记只允许用于验收。

### 6.7 本步验收

| 验收项 | 要求 |
| --- | --- |
| Walsh 正交性 | 理想同步下互相关为 0 |
| 三路分离 | 无噪声时同步、业务完全恢复 |
| 功率 | 合路前后实测功率与 `alpha` 配置一致 |
| 噪声 | 物理信道后只有一个噪声源，方差由 `Tsys/B/F` 或等价 `N0` 决定 |
| 相位校正 | 注入固定相位后，校正残差接近 0 |
| 帧同步 | 任意接收起点均能找到正确帧界 |
| 基线对比 | 关闭其他信道或分配相同有效 `Eb/N0` 时，业务 BER 回到相应基线 |

## 7. 第五步：去掉理想时钟同步，加入 Early-Late 跟踪

### 7.1 频差换算

老师给出的条件是 36.864 MHz 晶振存在 100 Hz 频差：

```text
relative_error = 100 / 36.864e6 = 2.7127 ppm
chip_clock_offset = 1.2288e6 * 2.7127e-6 = 3.3333 Hz
```

若不跟踪，Tx/Rx 码片边界每秒漂移约 `3.333 chip`。仿真必须模拟连续时间或分数采样偏移，不能简单地每隔固定整数 chip 删除一个样点代替完整时钟误差。

### 7.2 采样与插值结构

Early-Late 鉴相至少需要早、准、迟三个采样位置。建议前期采用 `4` 或 `8 sample/chip` 验证，硬件阶段改为插值器加定时 NCO：

```text
ADC samples -> 插值器 -> Early/Prompt/Late 相关器
                         -> 定时误差检测器
                         -> PI 环路滤波器
                         -> 定时 NCO/插值相位
```

### 7.3 Early-Late 误差

在当前估计码相位两侧取 `+/- Delta`，典型 `Delta=0.5 chip`：

```text
E = correlation at early phase
P = correlation at prompt phase
L = correlation at late phase
e[k] = |E|^2 - |L|^2
```

也可使用归一化误差：

```text
e_norm = (|E|^2-|L|^2) / (|E|^2+|L|^2+epsilon)
```

环路滤波器输出控制定时 NCO，使平均误差收敛到 0。PN 捕获负责把初始误差拉进跟踪范围，Early-Late 只负责小范围连续跟踪，二者不能互相替代。

### 7.4 相位校正的职责边界

定时环校正的是“什么时候采样”，导频相位环校正的是“复平面旋转多少”。如果 100 Hz 晶振同时作为射频本振参考，还会产生载波频偏；这应作为独立 CFO/载波相位模型，用导频 FLL/PLL 估计，不能指望 Early-Late 环消除载波旋转。

### 7.5 环路调试顺序

1. 无噪声、仅固定 0.25 chip 偏移，观察误差符号是否正确。
2. 无噪声、加入 2.713 ppm 频差，验证 NCO 能持续跟踪。
3. 加 AWGN，扫描环路带宽和阻尼系数。
4. 加逻辑信道功率分配，验证低导频功率下的跟踪门限。
5. 加正负 100 Hz 两种频差，防止环路只对一个方向有效。

### 7.6 验收标准

| 验收项 | 要求 |
| --- | --- |
| 捕获到跟踪 | 捕获后稳定切换，无 1 chip 跳变 |
| 稳态误差 | 平均定时误差接近 0，抖动满足设计值 |
| 频差范围 | `+100 Hz`、`-100 Hz` 晶振偏差均能跟踪 |
| 长时运行 | 至少跨多个 80 ms 超帧无滑码 |
| BER 损失 | 相对理想时钟基线的损失可量化且满足阶段预算 |
| 失锁处理 | 超门限后返回捕获，而不是继续输出错误数据 |

## 8. 第六步：固化单径 AWGN 链路，形成一个 Finger

### 8.1 本步目标

把前五步形成的接收算法封装为一条单径接收链路。该接收机既是 AWGN 条件下的完整接收机，也是下一步 Rake 的一个 Finger。

```text
Finger(path_delay)
  PN 相位/NCO
  Early-Prompt-Late 相关
  Walsh 解扩
  导频信道估计
  相位/幅度校正
  同步与业务软符号输出
  锁定质量指标
```

Searcher 不属于 Finger。Searcher 负责发现候选路径，Finger 负责对已分配路径做精跟踪和解调。

### 8.2 Finger 接口

| 输入 | 输出 |
| --- | --- |
| 复采样流 | 导频、同步、业务软符号 |
| 路径初始延迟 | `h_hat` 与路径功率 |
| PN 初相/超帧参考 | 定时误差与 NCO 相位 |
| 使能、复位 | `lock/quality/lost` 状态 |

`quality` 可综合导频相关峰、峰底比、信道估计功率和定时误差方差。后续 Finger 管理器用它判断路径保留或释放。

### 8.3 性能评估矩阵

| 变量 | 建议扫描 |
| --- | --- |
| 信道 | 理想、AWGN |
| 晶振频差 | 0、+100 Hz、-100 Hz |
| 固定相位 | 0、`pi/4`、`pi/2` |
| 起始码相位 | 随机覆盖一个 PN 周期 |
| 功率配置 | 默认配置及低导频功率边界 |
| 指标 | 捕获时间、失锁率、BER、帧同步率、相位/定时误差 |

本步结束时应冻结 `single_finger_float` 作为第七步的单径黄金基线。

### 8.4 验收标准

1. 单径、无噪声、任意 PN 初相和任意起始帧位置下端到端无误码。
2. 理想同步开关打开时，性能回到第四步基线。
3. 时钟跟踪打开时，相对理想同步的损失有独立曲线。
4. Finger 输入输出、延迟、更新率和有效信号全部固定。
5. 所有测试可由固定随机种子重复得到。

## 9. 第七步：构建 Searcher、两径信道与 Rake 接收机

### 9.1 两径信道

```text
r[n] = h0[n]*x[n-d0] + h1[n]*x[n-d1] + w[n]
```

初版先使用静态复增益，再加入慢变瑞利衰落。建议参数从简单到复杂：

```text
d0 = 0 chip
d1 = 2 chip
平均功率 = [0 dB, -3 dB]
初始相位 = [0, pi/3]
```

为了让两个 Finger 可分辨，初版路径间隔应大于接收脉冲的有效相关宽度。加入成形滤波后，还需明确延迟是 chip、采样点还是秒。

### 9.2 Searcher

Searcher 建立在第三步 PN 捕获器之上，但输出从“一个最佳峰”扩展为候选峰列表：

```text
candidate = {delay, metric, estimated_power, age}
```

搜索流程：

1. 在指定延迟窗内计算导频 PN 相关能量。
2. 找到最大峰并做门限确认。
3. 对已找到峰设置保护间隔，避免同一路径旁瓣重复入选。
4. 继续寻找下一峰，按能量排序。
5. 将未占用且超过门限的路径分配给 Finger。

Searcher 可以低速周期运行，不必每 chip 完整搜索一次。应分别定义捕获门限、保留门限和释放门限，形成迟滞，避免路径在门限附近反复启停。

### 9.3 Finger 管理

```text
FREE -> ACQUIRE -> TRACK -> WEAK -> RELEASE -> FREE
```

| 事件 | 动作 |
| --- | --- |
| 新路径超过捕获门限 | 分配空闲 Finger 并装载延迟 |
| 跟踪质量稳定 | 进入 TRACK，允许参与合并 |
| 路径连续低于保留门限 | 标记 WEAK，暂时降低或禁止权重 |
| 超过丢失计时器 | 释放 Finger，通知 Searcher 补搜 |
| 更强路径出现且无空闲 Finger | 比较质量后替换最弱路径 |

### 9.4 Rake 最大比合并

第 `m` 个 Finger 输出业务软符号 `y_m` 和信道估计 `h_hat_m`：

```text
z = sum_m conj(h_hat_m) * y_m
```

若各 Finger 噪声方差不同，应采用广义权重：

```text
z = sum_m conj(h_hat_m)/sigma_m^2 * y_m
```

合并前必须将各路径的同一业务符号按帧号和符号号对齐。仅把两个数组直接相加通常会造成路径间错位。软输出最好按总权重归一化，以保持后级译码器量度尺度稳定。

### 9.5 必做场景

1. 两径静态、已知时延：先验证两个 Finger 和 MRC 数学正确。
2. 两径静态、未知时延：启用 Searcher 自动分配。
3. 第二径运行中消失：验证释放和单 Finger 降级。
4. 第二径在新时延重新出现：验证重新搜索和重新分配。
5. 两径功率交叉变化：验证 Finger 不会频繁抖动切换。
6. 两径瑞利衰落：比较单 Finger、等增益合并和 MRC。

### 9.6 验收标准

| 验收项 | 要求 |
| --- | --- |
| 路径搜索 | 两径延迟估计在设计误差范围内 |
| 防重复 | 同一路径不占用两个 Finger |
| 符号对齐 | 合并的是同一帧同一符号 |
| MRC 增益 | 两径 MRC 优于最强单径，趋势符合理论 |
| 路径丢失 | 弱径消失后可继续单径工作 |
| 重搜索 | 新路径出现后能在规定时间内重新加入 |

## 10. 第八步：加入 FEC、CRC 与块交织，形成完整端到端链路

### 10.1 处理顺序

推荐发送顺序：

```text
信息 bit -> 组帧/CRC -> 卷积编码 -> 重复/速率匹配
         -> 块交织 -> 19.2 ksymbol/s 速率适配 -> Walsh 扩频
```

接收端严格逆序：

```text
Walsh 软符号 -> 去重复/软合并 -> 解交织
             -> 软判决 Viterbi -> CRC -> 信息 bit
```

交织器只作用于同步和业务信道，导频信道不编码、不交织。

### 10.2 同步信道

同步信道信息速率为 1.2 kbps。按老师给定参数：

```text
每同步数据帧时长 = 128 / 4800 = 26.666... ms
卷积编码输出速率 = 1.2 kbps * 2 = 2.4 kbps
重复后速率       = 4.8 kbps
每数据帧交织输入 = 128 bit
交织器           = 8 列 x 16 行
写入/读出         = 行入、列出
```

为了进入 19.2 ksymbol/s 的 Walsh 信道，交织后的 4.8 ksymbol/s 序列还需每符号重复 4 次：

```text
4.8 ksymbol/s * 4 = 19.2 ksymbol/s
```

三个 `26.666... ms` 同步数据帧组成一个约 `80 ms` 的完整同步帧。完整同步帧含 16 bit CRC。这里必须在参数表中进一步冻结：CRC 覆盖范围、CRC 多项式、CRC 插入位置、卷积码尾比特以及 80 ms 内净荷分配。仅凭“含 16 bit CRC”不足以唯一确定比特级实现。

同步帧的编码前总预算为：

```text
1.2 kbps * 80 ms = 96 bit
```

若 16 bit CRC 已包含在这 96 bit 中，且暂不考虑尾比特，则同步净荷最多为 80 bit；若卷积码采用显式尾比特，尾比特也必须占用这 96 bit，或由标准规定的终止方式另行处理。不能在 96 bit 之外直接追加 CRC 或尾比特，否则后续的 128 bit 交织块和 80 ms 帧长将不再成立。

### 10.3 业务信道

9.6 kbps 业务信道每 20 ms 包含：

```text
信息 bit 数          = 9.6e3 * 20e-3 = 192 bit
R=1/2 FEC 后         = 384 bit
交织器               = 24 列 x 16 行
写入/读出             = 行入、列出
编码符号率            = 384/20 ms = 19.2 ksymbol/s
```

因此 9.6 kbps 全速业务在编码和交织后可直接逐符号进行 64-chip Walsh 扩频。若加入 CRC 或卷积码尾比特，必须说明它们是否包含在 192 bit 内；否则帧长会超过 384 bit。2.4/4.8 kbps 模式应通过重复或删余规则适配到统一的 19.2 ksymbol/s 接口，规则按课程指定标准冻结。

### 10.4 块交织器索引

以 `R` 行、`C` 列为例，行入：

```text
matrix[r][c] = input[r*C+c]
```

列出：

```text
output[c*R+r] = matrix[r][c]
```

解交织执行逆置换。必须用递增序列 `0,1,2,...` 做单元测试，仅用随机 0/1 很难发现置换方向写反。

### 10.5 软判决与重复合并

重复符号在接收端先按对应关系累加软值，再送解交织和 Viterbi：

```text
LLR_combined = sum(LLR_repeat_i)
```

不能先对每个重复符号硬判决再多数表决，否则会损失软信息。Viterbi 译码必须固定终止方式、回溯深度、生成多项式顺序和软量度符号定义。

### 10.6 本步测试

| 层级 | 测试 |
| --- | --- |
| CRC | 单比特翻转必须检出；已知向量结果一致 |
| 卷积码 | 已知输入与编码输出逐比特一致 |
| 交织 | `deinterleave(interleave(x)) = x` |
| 无噪声链路 | 同步 CRC 通过，业务 BER/FER 为 0 |
| AWGN | 编码曲线优于未编码曲线 |
| 多径 | Rake + FEC 端到端稳定工作 |
| 帧统计 | 分开报告同步帧成功率、业务 BER 和业务 FER |

第八步完成后，浮点算法功能冻结。后续定点化和 RTL 不再改变算法含义，只改变数值表示和实现结构。

## 11. 第九步：完成定点优化

### 11.1 目标和比较口径

定点系统在 AWGN 信道目标 BER 或 FER 处，相对冻结的浮点完整链路性能损失不超过 0.4 dB：

```text
loss = EbN0_fixed(target) - EbN0_float(target) <= 0.4 dB
```

不要用单个随机点判断 0.4 dB。应使用足够统计量的曲线，在目标误码率附近插值，并给出置信区间。理论曲线用于检查浮点基线，定点损失应优先相对同算法浮点模型计算。

### 11.2 定点化流程

1. 在浮点模型记录每个节点的最大值、RMS、直方图和溢出概率。
2. 为输入、系数、乘积、累加器和状态量分别设计字长。
3. 明确每一级二进制点、舍入方式和饱和方式。
4. 建立位精确 bit-true 模型，不依赖宿主语言隐式类型转换。
5. 先逐模块与浮点比较，再跑端到端 BER/FER。
6. 从最敏感模块增加位宽，直至满足 0.4 dB 指标。
7. 冻结位宽表并生成 RTL 测试向量。

### 11.3 重点模块

| 模块 | 定点风险 | 检查重点 |
| --- | --- | --- |
| 合路器 | 三路峰值叠加 | 保护位、功率系数精度 |
| PN/Walsh 相关器 | 64 点或更长累加溢出 | 累加器增长位、分段缩放 |
| Searcher 能量 | 平方后动态范围大 | 平方位宽、非相干累加饱和 |
| 导频估计 | 低功率下量化噪声明显 | 平均窗、倒数或归一化精度 |
| Early-Late 环 | 小误差信号易被量化为 0 | 鉴相器、PI 状态、NCO 小数位 |
| MRC | 复乘和多径累加 | 权重归一化、软值尺度 |
| Viterbi | 路径量度持续增长 | 周期归一化、软输入位宽 |

相关器累加 `N` 个有符号输入时，理论上至少增加 `ceil(log2(N))` 个幅度位；还应为多信道峰均比和异常输入留保护位。

### 11.4 建议位宽表格式

| 节点 | 输入 Q 格式 | 输出 Q 格式 | 舍入 | 溢出 | 最大观测值 | 溢出次数 | 依据 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 示例：Walsh 累加器 | Q1.11 | Q8.11 | 最近偶数 | 饱和 | 待测 | 0 | 64 点累加 + 1 保护位 |

表中的位宽只是格式示例，不是推荐最终值。最终位宽必须来自本项目的波形统计和性能扫描。

### 11.5 验收标准

| 验收项 | 要求 |
| --- | --- |
| 模块一致性 | 固定向量下与 bit-true 参考逐点一致 |
| 溢出 | 正常工作范围内关键状态无未解释溢出 |
| AWGN 损失 | 目标 BER/FER 处不超过 0.4 dB |
| 同步性能 | 捕获率、跟踪抖动和失锁率满足浮点预算 |
| 多径性能 | Searcher/Finger/MRC 功能不因量化失效 |
| 可综合性 | 不使用动态数组、无限精度或不可实现运算假设 |

## 12. 第十步：RTL 设计与验证

### 12.1 RTL 划分

建议按算法边界划分模块：

```text
tx_source / crc_encoder / conv_encoder / interleaver
rate_matcher / walsh_spreader / channel_gain / channel_combiner
pn_i_generator / pn_q_generator / complex_spreader

sample_frontend / searcher / finger_0 / finger_1
timing_nco / interpolator / early_late_loop
pilot_estimator / rake_combiner / frame_sync
deinterleaver / viterbi_decoder / crc_checker
```

36.864 MHz 可作为单一主时钟，通过 clock-enable 产生 1.2288 MHz chip 使能及更低速率使能。优先使用同步时钟使能，减少人为制造的多时钟域；确需跨时钟域时必须使用 FIFO 或同步器并单独验证。

### 12.2 流接口

流接口至少包含：

```text
data
valid
ready（存在反压时）
frame_start
frame_end
channel_id
```

固定速率流水可不使用 `ready`，但必须明确下游永不阻塞。所有并行支路必须有延迟台账，特别是导频估计、业务数据、Finger 0/1 和帧标记。

### 12.3 实现要点

| 模块 | RTL 关注点 |
| --- | --- |
| PN/Walsh | LFSR 复位相位和 Walsh 地址必须确定 |
| 交织器 | 双口 RAM、乒乓缓存、读写地址置换 |
| Searcher | 相关器复用与搜索时延的权衡 |
| Finger | 两实例参数化，统一时间戳 |
| Early-Late | 插值器吞吐、NCO 相位累加精度 |
| MRC | DSP 复乘流水和饱和位置 |
| Viterbi | ACS 并行度、幸存路径存储、回溯延迟 |
| 帧控制 | 数据、有效信号和帧标志同延迟 |

### 12.4 四层验证

1. **模块单元测试**：每个 RTL 模块与第九步 bit-true 模型逐点比较。
2. **子系统测试**：Tx、Searcher/Finger/Rake、FEC 三个子系统分别验证。
3. **RTL 端到端测试**：使用无噪声、AWGN、多径、频差和路径丢失向量。
4. **板级/USRP 验证**：先线缆回环和固定衰减，再接信号发生器或无线环境。

比较点不能只有最终比特。建议保存：

```text
编码输出
交织输出
合路 chip
PN 相关峰
Finger Walsh 软符号
信道估计
MRC 输出
Viterbi 软输入与译码输出
```

第一个不一致节点通常就是问题所在。

### 12.5 RTL 最终验收

| 项目 | 要求 |
| --- | --- |
| 功能仿真 | 所有固定向量与 bit-true 模型一致 |
| 随机回归 | 不同帧、SNR、PN 相位、频差和路径组合通过 |
| 综合 | 无锁存器、无不可综合结构，资源符合器件预算 |
| 时序 | 目标 36.864 MHz 下无负裕量 |
| 复位 | 任意合法时刻复位后能重新捕获并恢复输出 |
| 板级 | 与软件定点模型关键节点或最终比特一致 |
| 性能 | 实测 BER/FER、捕获和跟踪性能满足系统指标 |

## 13. 推荐的软件和工程结构

## 14. 每一步统一的验收模板

阶段报告应按同一格式填写：

```text
1. 本步新增需求与不在本步处理的范围
2. 系统框图及相对上一版本的变化
3. 参数、数据率、帧长、功率和能量定义
4. 核心算法与接口
5. 单元测试和固定参考向量
6. 无噪声结果
7. AWGN/多径/频差结果
8. 与上一阶段基线的对比
9. 已知限制和下一步入口
10. 自动化验收结论
```

建议每一步至少记录以下指标：

| 类别 | 指标 |
| --- | --- |
| 数据正确性 | BER、FER、CRC 通过率 |
| 同步 | 捕获概率、虚警概率、捕获时间、失锁率 |
| 跟踪 | 定时偏差均值/RMS、相位误差均值/RMS |
| 多径 | 路径延迟误差、Finger 使用率、重捕获时间 |
| 数值 | 信号功率、噪声方差、溢出次数、量化 SNR |
| 硬件 | 资源、最高频率、时延、吞吐率 |

## 15. 关键排错表

| 现象 | 优先检查 |
| --- | --- |
| 第一步曲线固定平移约 3 dB | `Eb/Es`、复噪声 I/Q 方差、每符号 bit 数 |
| PN 解扩后接近随机 | PN 初态、移位方向、共轭、0/1 到 `+/-1` 映射 |
| 无噪声仍有固定误码 | 调制映射、群时延、帧标记和基线索引 |
| 相关峰总差 1 chip | PN 零相位定义、相关窗端点、流水延迟 |
| 多信道后性能异常 | Walsh 编号、码片对齐、功率权重是否误用 `alpha` 而非 `sqrt(alpha)` |
| 改逻辑信道功率时噪声也变化 | 错误地给每个逻辑信道单独加噪声 |
| Early-Late 越调越偏 | 早迟定义或环路反馈符号相反 |
| 相位仍连续旋转 | 存在 CFO，只做了定时跟踪或单次相位校正 |
| Rake 比单 Finger 更差 | 路径符号未对齐、权重未取共轭、噪声重复计入 |
| 路径消失后系统卡死 | Finger 释放、Searcher 重启或状态机超时缺失 |
| FEC 后反而变差 | 软值符号、交织方向、卷积码多项式顺序、尾状态 |
| 定点出现误码平台 | 累加器溢出、环路状态量精度不足、Viterbi 量度饱和 |
| RTL 偶发错位 | `valid`、帧标记和数据流水延迟不一致 |

## 16. 最终交付清单

完成十步后，应交付：

1. 系统规范：参数表、帧结构、功率预算、接口和延迟台账。
2. 十个阶段的浮点仿真入口及自动回归脚本。
3. PN、Walsh、卷积码、CRC、交织器的标准参考向量。
4. 单径和两径信道模型，Searcher、Finger 管理器和 Rake 模型。
5. BER/FER、捕获、跟踪、多径和路径重搜索性能报告。
6. 位精确定点模型、全节点位宽表和不超过 0.4 dB 的证据。
7. RTL 源码、testbench、测试向量、综合及时序报告。
8. C/模型、RTL、FPGA/USRP 的逐点或逐比特一致性报告。

十步法的核心原则是：先建立可证明正确的最小基线，再逐层取消理想假设。每一步都必须能说明“新增了什么非理想因素、用什么算法处理、相对上一基线付出了多少性能代价”。做到这一点，完整 CDMA 链路就不再是难以定位问题的单体工程，而是一组边界明确、可独立验收的通信模块。
